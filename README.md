# Predicting 30-Day Patient Readmission Using Machine Learning

## Project Overview

This project explores how machine learning can be used to predict whether a patient is likely to be readmitted to hospital within 30 days of discharge.

Using Python and Databricks, I analysed patient data, explored factors associated with readmission, and developed classification models to investigate their predictive performance.

The project was completed as part of my data analytics and machine learning training.

## Project Objectives

- Explore and clean the patient dataset.
- Identify patterns and factors associated with hospital readmission.
- Prepare the data for machine learning.
- Train and compare classification algorithms.
- Evaluate model performance and identify opportunities for improvement.

## Tools and Technologies

- **Python** – Data analysis and machine learning
- **Databricks** – Data processing and notebook development
- **Pandas and NumPy** – Data cleaning and manipulation
- **Matplotlib and Seaborn** – Data visualisation
- **Scikit-learn** – Model training and evaluation

## Dataset

The dataset contains patient information used to investigate 30-day hospital readmission.

Some of the features examined include:

- Age and gender
- Length of hospital stay
- Number of diagnoses
- Blood pressure and blood sugar levels
- Previous hospital admissions
- Admission type

**Target variable:** Readmission (Yes or No).

## Project Workflow

### 1. Data Preparation
I examined the dataset, checked for missing values and duplicates, and prepared the variables for modelling. Categorical features were encoded, and numerical features were scaled where appropriate.

### 2. Exploratory Data Analysis (EDA)
I used visualisations to understand the distribution of patient characteristics and investigate possible relationships with readmission.

### 3. Machine Learning
I explored supervised classification algorithms, including:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

I compared model performance and investigated ways to improve predictions.

### 4. Model Evaluation
I used classification evaluation techniques, including ROC-AUC, to assess how effectively the models distinguished between patients who were readmitted and those who were not.
